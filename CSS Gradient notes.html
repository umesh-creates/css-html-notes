🎨 CSS Gradient

🔹 Gradient क्या होता है?

👉 Gradient मतलब 2 या उससे ज्यादा colors का smooth transition (धीरे-धीरे बदलना)

📌 Example:
red → blue (बीच में कई shades बनते हैं)

🔹 Gradient के प्रकार

1️⃣ Linear Gradient

👉 सीधी line में color change होता है

📌 Syntax:

background: linear-gradient(direction, color1, color2, ...);

📌 Example:

background: linear-gradient(to right, red, blue);

👉 मतलब:
left से right → red से blue

🎯 Direction समझो

Direction मतलब
to right left → right
to left right → left
to top bottom → top
to bottom top → bottom

📌 Angle से भी दे सकते हैं:

background: linear-gradient(45deg, red, blue);

2️⃣ Radial Gradient

👉 center से गोल (circle) में color फैलता है

📌 Syntax:

background: radial-gradient(color1, color2);

📌 Example:

background: radial-gradient(red, yellow);

👉 center में red → बाहर yellow

3️⃣ Conic Gradient

👉 circle में घूमते हुए color change होता है

📌 Example:

background: conic-gradient(red, blue, green);

👉 pie chart जैसा look आता है

🔹 Multiple Colors Gradient

background: linear-gradient(to right, red, yellow, green);

👉 red → yellow → green smoothly change होगा

🔹 Color Stop (Control करना)

👉 तुम decide कर सकते हो कौन सा color कहाँ तक रहेगा

background: linear-gradient(to right, red 20%, blue 80%);

👉 red = 20% तक
👉 blue = 80% से end

🔹 Transparent Gradient

👉 opacity effect के लिए

background: linear-gradient(to right, rgba(255,0,0,0), red);

👉 transparent → red

🔹 Text Gradient (Pro Trick 🔥)

background: linear-gradient(to right, red, blue);
-webkit-background-clip: text;
color: transparent;

👉 text के अंदर gradient दिखेगा

🔹 Important Tips

✔ gradient हमेशा background में use होता है

✔ images की जगह gradient use कर सकते हो

✔ button, card, text — सबमें use होता है

✔ modern UI में बहुत use होता है
